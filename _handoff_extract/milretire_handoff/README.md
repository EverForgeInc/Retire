# Military Retirement App Developer Handoff

This package is designed to be uploaded into a programming AI or given to a software developer.

## Start here

1. Upload the entire ZIP.
2. Tell the coding AI to open `MASTER_BUILD_PROMPT.md`.
3. Instruct it to treat `checklist_data.json` as the canonical checklist dataset.
4. Ask it to generate the complete runnable MVP, not a mockup.

## Package contents

- Product requirements
- Structured checklist JSON
- Flat CSV
- Business rules
- Database schema
- OpenAPI specification
- UI specification
- Security and privacy requirements
- Acceptance tests
- Master build prompt
- Personalized fillable PDF reference

## Important

The checklist is a planning foundation and must support policy updates, official-source versioning, and local installation overrides. The application must not present itself as an official government system.
